# Depression — мод для Minecraft (Fabric 1.20.1)

Добавляет эффект **«Депрессия»**. Он не берётся из зелий — он накапливается сам, исходя из того, как ты играешь.

## Что ухудшает настроение (каждую секунду)
- темнота (уровень света ≤ 4)
- одиночество: рядом нет игроков, твоих питомцев и жителей
- больше 3 игровых суток без сна
- здоровье ≤ 3 сердец

## Что помогает
- другой игрок рядом (16 блоков): −2
- твой приручённый питомец рядом (8 блоков): −2
- солнечный день под открытым небом: −2
- житель деревни рядом: −1
- сон в кровати: сразу −900

Шкала от 0 до 2400, уровни эффекта — на 600, 1200 и 1800. Чем выше уровень, тем медленнее ходьба и удар, и тем меньше максимальное здоровье. Шкала сохраняется между перезапусками, после смерти сбрасывается. В творческом режиме и режиме наблюдателя не действует.

## Команды (нужен уровень оператора 2)
- `/depression get` — показать текущее значение
- `/depression set <0..2400>` — задать значение

## Сборка
Нужны JDK 17 и Gradle (или Gradle wrapper):

```
gradle build
```

Готовый мод: `build/libs/depression-1.0.0.jar`. Положи его в папку `mods` вместе с Fabric Loader и Fabric API 0.92.2+1.20.1.

Все числа (пороги, радиусы, штрафы) лежат в `DepressionManager.java` и `DepressionEffect.java`, их легко подкрутить.
